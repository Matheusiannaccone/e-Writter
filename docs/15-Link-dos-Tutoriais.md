## Convenção para manutenção deste documento

Ao adicionar um novo tutorial:

1. escolha a seção correspondente ao assunto;
2. use um título curto e descritivo;
3. informe o objetivo do vídeo;
4. liste os principais assuntos abordados;
5. adicione o link público do vídeo;
6. mantenha a numeração dos tutoriais em ordem crescente.

Evite remover links antigos enquanto o conteúdo ainda for útil para a equipe. Caso um tutorial seja substituído por uma versão mais recente, identifique claramente qual é o material recomendado.
